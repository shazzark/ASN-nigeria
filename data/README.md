# Generated data

The root files in this directory combine AFRINIC and APNIC extended delegated-statistics records with country `NG` and active `allocated` or `assigned` status. This is registry allocation data. It does not establish where an address is physically used or whether it is currently announced in BGP. The country code is the source's code recorded for an allocation or assignment. Scope is limited to those two sources; the files do not claim complete all-RIR coverage.

`ASN.Nigeria.list` and `asns.txt` contain ASN numbers; `IPv4.Nigeria.list` and `IPv6.Nigeria.list` contain exact converted allocation prefixes; `IP.Nigeria.list` combines those address lists. `networks.json`, `resources.json`, and `metadata.json` retain claims and source provenance. `networks.json` also includes DB-IP ASN Lite organization labels where available, with the release and all candidate labels and counts. These labels are not registry names or proof of Nigerian registration; missing labels stay null. `surge/` and `quantumult-x/` contain their respective rule syntax and source comments.

The `country-ip/` directory is a separate DB-IP Lite classification dataset. Its IP files contain address ranges that DB-IP classifies as Nigeria (`NG`). DB-IP Lite is a reduced-coverage, reduced-accuracy subset, so these files do not cover every address. Its ASN files list an ASN if the IP-to-ASN Lite dataset maps at least one address overlapping an NG-classified country range to that ASN. That association is not a registry assignment. `country-ip/resources.json` retains inclusive DB-IP endpoints and their exact minimal CIDR conversion; `country-ip/metadata.json` records source release, checksum, full source row totals, selected NG range counts, attribution, license, and collection time. Client-specific output is under `country-ip/surge/` and `country-ip/quantumult-x/`.

DB-IP's free IP to Country Lite and IP to ASN Lite downloads are licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The project credits DB-IP.com and indicates its modifications (filtering to NG, converting inclusive ranges to minimal CIDRs, and formatting proxy rules). The official [country Lite page](https://db-ip.com/db/download/ip-to-country-lite), [ASN Lite page](https://db-ip.com/db/download/ip-to-asn-lite), and [DB-IP terms](https://db-ip.com/tos.php) provide source and license details. The MIT license in the repository applies to original code, not source data.

The AFRINIC [extended statistics notice](https://ftp.afrinic.net/stats/afrinic/README-EXTENDED.txt) permits download and use subject to its disclaimer, but does not expressly address transformed public redistribution or automated publication. APNIC's [extended statistics notice](https://ftp.apnic.net/stats/apnic/README-EXTENDED.TXT) also permits free download and use subject to a disclaimer. The project attributes both sources and records their terms in `metadata.json`. RIPE's terms are incompatible with republication of data from covered services unless that service permits it, so RIPE records are excluded. ARIN and LACNIC are not included; all-RIR completeness is not claimed. DB-IP geolocation associations are supplemental and do not replace registry allocation records.

The collector fetches and validates all sources before replacing outputs. A failure preserves the last complete generated dataset. Updates run daily and on manual dispatch, but DB-IP Lite releases are monthly; daily checks use the latest release reported on DB-IP's official pages. The update workflow commits generated files only when dataset records change. These are snapshots, not real-time lists.
