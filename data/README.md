# Published data

These generated files contain AFRINIC extended delegated-statistics records for active `NG` allocations and assignments. The country code identifies the resource holder's registered country; it does not establish the physical location of every address or show whether a prefix is currently announced in BGP.

## Source and attribution

Source: [AFRINIC extended delegated statistics](https://ftp.afrinic.net/stats/afrinic/delegated-afrinic-extended-latest). The [AFRINIC statistics README](https://ftp.afrinic.net/stats/afrinic/README-EXTENDED.txt) says the files are freely available for download and use subject to a condition that AFRINIC will not be held responsible for loss or damage arising from report information. This project preserves that attribution and disclaimer in `metadata.json`.

The source notice does not expressly discuss public redistribution of transformed lists or automated publication. These files are published under the project's interpretation of the source's broad download-and-use wording; AFRINIC has not confirmed this interpretation, and no legal certainty is claimed. This repository's MIT license applies to its original code, not these generated source-derived data files.

## Refresh and formats

The GitHub Actions workflow validates and refreshes these files daily and can be triggered manually. It commits only when generated resource lists change. See the repository README for collection details and Surge and Quantumult X output formats.
